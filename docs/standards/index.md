# Code Atlas 架构规范索引

## 版本

0.1 · 讨论基准

## 目标

按功能组织、按职责隔离、按契约连接；地图反映证据，不代替真实重构。

## 整理路线

1. 固定现状：保存源码提交、原始报告、现有功能与行为回归。分析不执行目标代码。
2. 定义功能树：先分 E3D 启动、许可连接、工具部署、配置与页面职责；标注共享与未知。
3. 选一个纵向切片：优先 LaunchAsync，从页面点击到校验、探测、参数准备和进程启动逐段列证据。
4. 提取契约：启动用例、许可探测、配置读取和进程执行端口；请求/结果不依赖 WPF。
5. 拆计算与作用：提取纯参数规则，文件检查和 Process.Start 保留在适配器，用例负责顺序。
6. 拆页面状态：LaunchPageViewModel 只调用启动用例，LicensePageViewModel 维护连接页面状态。名称是建议。
7. 显式组合与可选分发：集中 Fluent 注册，验证无私有许可/AI DLL 时公共入口仍可启动。
8. 补充源码声明并回归：用途、输入输出、状态作用、源信息；逐步用真实声明取代人工映射。
9. 再扩展检查能力：注册、模块 ID 与反例映射可以自动取证；分发闭包和热卸载尚未实现时，不能用空结果宣布通过。
