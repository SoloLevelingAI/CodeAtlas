# A07 · 主干与可选模块能真正拆装

## 规范要求

宿主只依赖稳定契约。模块声明 ID、版本、能力、必需/可选依赖、页面与注册。Fluent API 表达组合，不意味着必须把所有类注册到容器。

## 为什么这样分

启动、许可工具、AI 管理及未来模块可以分别添加、移除和分发；UI 上隐藏不等于包里没有 DLL。

## 自动检查范围

仅部分注册证据可分析。模块清单兼容性、客户分发闭包与热卸载验证目前未实现；禁止给出已通过结论。

## 关联诊断

无自动诊断规则

## 整理建议

先实现构建时可选组装与分发，验证删除模块后的剩余闭包。热插拔是单独能力，不要求首版实现；私有许可/AI 实现不能被公共入口强引用。

## 验收条件

公开包实际不含私有 DLL；移除可选模块后仍能构建启动；必需依赖缺失时报出明确原因。
