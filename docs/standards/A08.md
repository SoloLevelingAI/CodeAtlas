# A08 · 地图有证据，也保留盲区

## 规范要求

节点携带稳定标识、用途、源码位置和归属来源。区分源码自声明、人工映射、静态关系与运行时证据；缺失和不支持内容必须可见。

## 为什么这样分

清晰的设计图不能掩盖代码遗漏，也不能把静态引用画成已经发生的调用。

## 自动检查范围

部分自动：AT200–AT210 与覆盖统计；完整项目编译、XAML 绑定和运行目标解析尚不支持。

## 关联诊断

AT200, AT201, AT202, AT203, AT204, AT205, AT206, AT207, AT208, AT209, AT210

## 整理建议

保留原始报告和源码快照；人工归属另存清单。无声明代码仍可搜索，缺失说明不从函数名伪造。

## 验收条件

每个证据跳回正确文件与行；人工整理不增加源码已声明计数；重分析结果可对比。
