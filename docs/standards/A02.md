# A02 · 功能实现分别独立

## 规范要求

每个子功能拥有自己的业务计算或规则实现；命名为 Core 的项目不自动成为核心。计算只依赖明确的输入、同职责能力和契约，通过用例连接外部作用。

## 为什么这样分

功能的核心是自身规则，不能把不同功能实现全部揉进一个类或 DLL。

## 自动检查范围

部分自动：AT101 检查已声明职责的越层引用；LD001 是 LaunchDesk 的人工证据。

## 关联诊断

AT101, LD001

## 整理建议

例如把启动参数计算从文件校验和进程创建中提取，形成 LaunchPlanBuilder、校验端口和执行端口。它们是建议名称，并非已存在的实现。

## 验收条件

参数计算可以用固定输入独立测试；替换进程执行器不影响计算代码。
