# A03 · 页面交互有自己的边界

## 规范要求

每个页面的 ViewModel 管理该页面的选择、表单、命令、忙碌状态与显示。通过用例契约接入功能；不依赖具体后端类型，不直接做网络、数据库或进程操作。

## 为什么这样分

对交互而言 ViewModel 是核心；对业务而言它是调用方，两种视角不能混淆。

## 自动检查范围

部分自动：AT101 检查已声明职责的越层引用；AT105 检查交互角色直接调用已知文件、网络、时钟或进程作用。页面如何划分、移除模块后是否仍能运行，仍需人工和场景回归。LD002 为人工问题。

## 关联诊断

AT101, AT105, LD002

## 整理建议

把启动、许可连接、工具部署的状态拆成独立页面 ViewModel。共享导航状态留在窗口壳，用例承接跨功能流程。

## 验收条件

用假的用例端口即可验证页面交互；移除某个可选模块后其它页面仍能运行。
