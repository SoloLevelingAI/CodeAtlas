# A04 · 契约说明意图，不藏实现

## 规范要求

端口接口、请求和结果描述调用意图与输入输出。契约不包含默认业务实现，不把 UI 控件、数据库会话或具体适配器作为通用交换对象。

## 为什么这样分

稳定的契约才允许替换后端、复用页面和拆分模块。数据类型有计算属性时也不能直接认定为纯契约。

## 自动检查范围

部分自动：AT003 检查声明实现关系，AT104 检查契约行为，AT106 检查契约签名里的 UI 控件、存储会话和具体适配器类型。同一张图里的具体职责类型仍由 AT101 报告。签名没被静态绑定时保持为未支持，不把缺席诊断当成签名合格。契约命名是否达意仍需人工判断。

## 关联诊断

AT003, AT104, AT106

## 整理建议

先提取最小用例端口，再替换调用点。按实际变更边界决定契约程序集，不要求每个接口都单独建项目。

## 验收条件

调用方仅引用契约；实现程序集可以替换；输入输出语义清楚且不携带页面状态对象。
