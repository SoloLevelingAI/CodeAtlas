# A06 · 数据访问与外部作用通过适配器

## 规范要求

CRUD、文件、网络、系统服务、渲染设备和进程创建属于各功能的外部适配。规则计算通过端口使用它们；CRUD 与验证/合并规则按职责拆开。

## 为什么这样分

外部作用需要替换、隔离与失败处理，不应侵入所有功能核心或页面。

## 自动检查范围

部分自动：AT101/AT102 检查越层和核心外部作用；AT105 检查页面上的已知外部作用；AT107 检查用例编排直接调用已知文件、网络、数据库或进程作用。报告上的时钟戳不单独当成适配器违规。适配器自身的文件访问是其职责，不据此报错。LD003 指出 LaunchDesk 存储类混合职责。

## 关联诊断

AT101, AT102, AT105, AT107, LD003

## 整理建议

先保留原行为，拆出工作区存储端口与配置验证/合并规则，再由用例控制读写顺序。

## 验收条件

可用内存适配器跑用例；写入失败保持旧数据；路径、权限与取消行为有测试。
