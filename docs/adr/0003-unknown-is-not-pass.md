# ADR-0003：未知不是通过

状态：接受。日期：2026-10-18。

背景：自分析、规范评估和目标模型对照都会遇到“这次没有看见证据”。如果把没有诊断、读失败或尚未实现的检查写成通过，退出码 0 就会被当成认证。

决策：缺少目标模型、模型无法读取、完全看不到注册、以及规范里写了但本次源码图无法证明的检查，结果都是未知或不支持，不是通过。AT122 使用 `FindingSeverity.Unsupported`。默认 `check` 仍以规则错误作为退出码 2；未知项保持可见，不因为“没有 AT125”就宣布架构已经对齐。页面文案同样写明：这一层没有漂移诊断，只说明当前图没有这几条已知差异。

取舍：不把未知升级成错误，以免在模型尚未提供时让所有仓库的默认检查失败。需要门禁时使用警告基线或显式严格选项，而不是把缺失证据静默成成功。

后果：`ArchitectureGuide` 继续把任何不支持项解释为证据不足。新增规则必须同时有反例和规范映射，否则 AT120 / AT121 会在独立回归里失败。
