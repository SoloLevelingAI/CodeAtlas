# ADR-0002：先做成模块化单体

状态：接受。日期：2026-10-18。

背景：功能、职责、模块和程序集回答的不是同一个问题。把每个逻辑模块拆成独立进程或独立 DLL，会在协议还没有稳定字段时引入部署、版本和调用边界。

决策：CodeAtlas 保持一个进程内的模块化单体。`ModuleDescriptor` 表达可选择的启动单位，父级用显式 `ParentId` 表示，ID 里的点没有层级含义。多个逻辑模块可以留在同一个程序集里。宿主通过 Profile 选择入口，Composition 补齐父级和必需依赖后再接线。

取舍：物理裁剪、客户包资源、热卸载和跨进程插件清单都不在这一轮。Headless 只表示不注册探索视图，不表示发布包已经删掉 DLL。

后果：运行模块、源码功能目录和 LikeC4 目标模型可以分别对照，但不能互相推断。后续若要拆进程，必须先有独立的契约版本和部署证据。
